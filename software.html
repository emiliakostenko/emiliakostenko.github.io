Software and Engineering Enhancement

This enhancement will demonstrate my skills and abilities in software design and engineering.

Narrative

The artifact that I selected is my inventory tracking mobile app from CS360. The original version allowed users to perform CRUD operations for inventory items. Users were able to manage and keep track of inventory with screens for logging in, adding items, displaying current items, and managing item amounts. This app was created in October 2025.

This artifact will help me showcase skills that will make me more marketable. These include building an application that supports a diverse audience and is technically sound, showcasing innovative techniques. Techniques such as employing a binary search tree for efficient information retrieval and building an intuitive app through Android Studio that utilizes an SQLite database showcase technical skills. Additionally, this will showcase my ability to apply secure coding practices to reduce security vulnerabilities through proper error handling, input validation, authentication, and authorization. To improve my artifact, I added four new features, which include adding a search functionality, a feature to manage inventory items by a custom amount, adding folders to store inventory items in, and creating a description page for individual inventory items. A couple of the enhancements require data structure and database work, which will be implemented in later milestones.

The course outcomes that I planned to meet with this enhancement were:

  • Employ strategies for building collaborative environments that enable diverse audiences to support organizational decision-making in the field of computer science.
  • Design, develop, and deliver professional-quality oral, written, and visual communications that are coherent, technically sound, and appropriately adapted to specific audiences and contexts.
  • Develop a security mindset that anticipates adversarial exploits in software architecture and designs to expose potential vulnerabilities, mitigate design flaws, and ensure privacy and enhanced security of data and resources.
I applied enhancements that aligned with these course outcomes. The application enables diverse audiences and supports organizational decision making and is built with safeguards to avoid exploitation and ensure security of data and resources. The second course outcome has not necessarily been met with the coding enhancements but will be part of the portfolio project. I don’t have any updates to my outcome coverage plans.

Reflection

As I enhanced my artifact, I realized that there was a lot more to the enhancements than I planned. While I thought I planned my enhancements with all possible scenarios in mind, when adding enhancements and editing the application, I realized there were more components that needed to be added than originally anticipated to make the new features work as planned and be user intuitive. This aligns with developing in the real-world and why iterative development is beneficial. Oftentimes, even when all the features are planned out, development helps uncover things that are needed that may not have been considered during the planning stage.
