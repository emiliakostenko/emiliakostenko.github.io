Reflection

My initial plan to add a binary search tree was to add a method within an existing activity class. After looking through my previous class notes and projects, I decided to implement a separate class to declare the binary search tree and its methods. From there I was able to call the methods in the activity class where the search bar was located. While the plan for the functionality did not change, the plan for implementation did to keep the activity method clean, improve maintainability, and have clear separation of concerns.
